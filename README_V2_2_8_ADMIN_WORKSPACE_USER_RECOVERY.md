# 정참시 v2.2.8 — Admin Workspace + User Recovery

## 변경 사항
- 관리자 화면을 단일 장문 페이지에서 메뉴형 워크스페이스로 개편했습니다.
- 메뉴: NOW Rank Refresh / 관리자 보안 / 방문자 표시 관리 / 회원 관리 / 운영 상태.
- 데스크톱은 좌측 고정·스크롤 메뉴, 좁은 화면은 상단 가로 스크롤 메뉴로 전환됩니다.
- 회원 정보는 `회원 관리` 메뉴를 열었을 때만 API로 조회합니다.
- 회원 목록에서는 이메일과 UUID를 기본 노출하지 않고, `관리` 버튼을 눌러 상세 화면에서 확인합니다.
- 관리자는 회원의 아이디와 등급을 변경할 수 있습니다.
- 관리자는 기존 비밀번호를 열람할 수 없으며, 본인 확인 후 **새 비밀번호 설정(재설정)** 만 가능합니다.
- 회원 비밀번호를 재설정하면 `sessionVersion`을 증가시켜 기존 회원 로그인 세션을 즉시 무효화합니다.
- 아이디 변경 시 기존/신규 username index를 함께 갱신합니다.

## 배포
랭킹 모델이나 공개 스냅샷 구조 변경이 없으므로 배포 후 NOW Rank Refresh는 필요하지 않습니다.
