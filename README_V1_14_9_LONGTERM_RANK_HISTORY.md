# NOW Rank v1.14.9 · Long-term Rank History

## 핵심 변경
- 의원 상세 `NOW Rank 변화 추적`을 직전/현재 2점에서 실제 게시 이력 시계열로 확장.
- 수동 게시/롤백 때마다 299명의 `id + rank + score`만 담은 초경량 장기 이력을 별도 Redis 리스트에 저장.
- 장기 이력은 최대 1,500회 게시 포인트 보존. 기존 전체 스냅샷 112개 제한은 롤백/관리자 용도로 그대로 유지.
- 기존에 쌓인 전체 스냅샷도 상세 그래프에서 자동 병합하므로 배포 직후부터 가능한 과거 점을 표시.
- 상세 그래프 기간 선택: 24시간 / 7일 / 30일(기본) / 1년.
- 현재 / 기간 최고 / 기간 최저 / 기간 순변화 표시.
- 데이터 포인트가 많아도 SVG는 LTTB 방식으로 최대 72개 대표점만 그려 모바일 렌더링 부하를 억제.
- 동명이인/재보선 교체 안전성을 위해 현재 rosterVersion과 의원 id를 기준으로 시계열을 분리.

## 저장 원칙
- Refresh 초안은 기록하지 않음.
- 실제 `게시`가 발생한 시점만 한 점으로 저장.
- 현재 수동 게시: MANUAL
- 롤백 게시: ROLLBACK
- 추후 13시 자동 게시 연결 시 같은 helper에 AUTO만 전달하면 동일 시계열에 이어서 저장 가능.

## 배포
ZIP 전체를 GitHub 저장소 루트에 덮어쓴 후 Vercel 배포.
새 장기 이력은 다음 게시부터 계속 누적되며, 과거 112개 전체 스냅샷 범위는 자동으로 그래프에 병합된다.
