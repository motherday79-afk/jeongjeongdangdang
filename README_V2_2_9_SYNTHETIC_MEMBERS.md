# 정참시 v2.2.9 — Synthetic Demo Members

- 관리자 회원관리 화면에 시연용 임의회원 150명을 안정적으로 표시합니다.
- 임의회원은 `isSynthetic: true`이며 관리자 화면에서 닉네임 뒤 `*`로 구분합니다.
- 이메일은 시연 화면의 현실감을 위해 `naver.com` / `gmail.com` 형식으로 표시하지만, 실제 인증/메일발송/로그인 계정으로 사용하지 않습니다.
- 실제 Redis 회원 데이터와 완전히 분리되어 실제 회원 ID/비밀번호/회원수 데이터에 영향을 주지 않습니다.
- 시연회원 등급은 FREE/PLUS/PRO가 자연스럽게 섞여 있고 가입일/최근활동 시각도 고정된 샘플 분포를 사용합니다.
- 실제 회원에 대한 관리자 아이디 변경/비밀번호 재설정 기능은 v2.2.8과 동일하게 유지됩니다.
