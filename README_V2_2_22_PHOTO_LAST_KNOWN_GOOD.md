# 정참시 v2.2.22 · 정부 주요인사 사진 안정화

- 한성숙 국무총리: 국무조정실·국무총리비서실 공식 프로필 사진을 고정 우선 소스로 등록
- 공식 프로필: https://www.opm.go.kr/opm/prime/profile.do
- 기존 정상 사진(last-known-good) 메타데이터는 새 후보가 실제 이미지 응답에 성공하기 전까지 삭제하지 않음
- 원본 이미지가 순간적으로 실패하면 서버에서 재검색 후보 검증 후 교체하며, 새 후보도 실패하면 기존 원본을 한 번 더 재시도
- 브라우저도 서버 프록시 실패 시 즉시 기본 이미지로 떨어지지 않고 캐시버스터를 사용해 1회 재요청
- 정부 주요인사/국회의원/지방단체장 전체에 동일한 last-known-good 보호 원칙 적용
- 한성숙 총리 취임일 표기를 국무총리실 공식 약력 기준 2026.07.01로 정정
