# 정참시 v2.2.18 · 사진 검수 복구 워크플로우

v2.2.16에서 추가한 `전체 인물 사진 검수`가 문제를 발견한 뒤 운영자가 복구할 수 있는 경로가 부족했던 점을 보완한 패치입니다. v2.2.17의 회원정보/NOW ISSUE/자체 설문조사 기능은 그대로 유지합니다.

## 관리자 사진 검수 화면

- 기존 542명 전체 검수 유지
- `문제 N명 자동 복구` 버튼 추가
  - 검토 필요/실패 항목만 대상으로 동작
  - 정상 사진은 다시 검색하지 않음
  - 복구 검색은 1차 검수보다 넓은 검색어와 Bing async 결과까지 순차 확인
  - 한 번에 많은 외부 요청을 몰지 않도록 2명 단위 순차 처리
- 각 문제 행에 `자동복구` 버튼 추가
- 모든 인물 행에 `직접 등록/사진 교체` 버튼 추가
- 직접 등록 시
  - 사진 HTTPS URL
  - 원문/프로필 페이지 URL
  - 출처 표시
  를 입력할 수 있음
- 직접 등록 사진은 서버가 실제 이미지 응답과 해상도를 확인한 뒤 저장하고 즉시 재검수
- 직접 등록값 삭제 후 자동 사진 경로로 복귀 가능

## 자동 복구 로직

1. 현재 사진을 다시 검사
2. 문제가 있는 경우에만 캐시를 비우고 심층 재검색
3. 공식 후보와 검색 후보를 비교
4. 기존 사진보다 나쁜 후보로는 교체하지 않음
5. 관리자 직접 등록 사진이 깨졌고 자동 검색에서 더 나은 사진을 찾은 경우 잘못된 직접 등록값을 제거하고 정상 후보로 복구
6. 끝까지 자동 복구가 안 되는 인물은 `직접 등록`으로 운영자가 마무리

## 지방단체장 공식 출처 보강

대한민국시장군수구청장협의회 회원 목록에서 이름만 찾는 기존 방식에 더해, 해당 인물의 상세 회원 페이지 링크를 찾아 상세 프로필의 사진을 우선 확인하도록 보강했습니다.

## 기존 검수 부하 완화

전체 검수 API의 처리 단위를 최대 4명 병렬에서 최대 2명 순차 처리로 줄였습니다. 대량 검수 중 이미지 검색/원문 페이지에 요청이 몰려 일시 실패가 늘어나는 문제를 완화하기 위한 변경입니다.

## 유지되는 기능

- 죽은 사진 URL 캐시 폐기 후 자동 1회 재검색
- 542명 전체 사진 검수
- NOW / 정뮤니티 / News / 정치인 상세 브라우저 history
- v2.2.17 회원가입 정보 구조 및 MY 수정
- 관리자 NOW ISSUE 제어
