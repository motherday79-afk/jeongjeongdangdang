# 정참시 v2.2.11 · Editorial Scheduler

## 메인 메뉴
PC·모바일 메뉴 순서를 아래처럼 통일했습니다.

1. 실시간 인물순위
2. 정뮤니티
3. 정참시News
4. 비교분석
5. MY

기존 `정참시 커뮤니티` 표시는 `정뮤니티`, 기존 `정정뉴스` 표시는 `정참시News`로 변경했습니다.

## 관리자 콘텐츠 CMS
관리자 왼쪽 메뉴에 아래 2개 메뉴를 추가했습니다.

- 정뮤니티 관리
- 정참시News 관리

두 메뉴 모두 `작성 대기함 저장 → 검토/수정 → 지금 게시 / 예약 게시` 흐름을 지원합니다.
작성 대기함에서 여러 항목을 체크해 `선택 게시`할 수도 있습니다.
예약 취소, 대기글 삭제, 게시 상태 확인도 가능합니다.

정뮤니티의 관리자 작성 콘텐츠는 일반 회원을 사칭하지 않고 `정참시 운영팀` 명의로 게시합니다.
정참시News의 관리자 작성 콘텐츠는 `정참시News 편집부` 명의로 게시합니다.

## News 이미지
정참시News 예약 기사도 대표 이미지를 첨부할 수 있습니다.
브라우저에서 1200×675(16:9)로 중앙 크롭 및 WEBP/JPEG 최적화를 거친 뒤 저장합니다.
서버 저장 한도는 최적화 결과 1.2MB입니다.

## 예약 게시 동작
예약 정보는 Redis 작성 대기함과 예약 Sorted Set에 저장됩니다.
예약 시간이 지난 콘텐츠는 다음 요청에서 안전하게 게시 큐를 비웁니다.

- 사이트 방문 통계 heartbeat: 최초 접속 + 약 2분 주기
- 정뮤니티/정참시News 목록 요청
- 관리자 예약 큐: 약 1분 주기 및 새로고침

따라서 일반적인 시연/운영 트래픽에서는 예약 시각 직후 자동 게시됩니다. 완전히 트래픽이 없는 동안에는 다음 사이트/API 요청 시 게시됩니다.

분 단위 Vercel Cron을 `vercel.json`에 강제하지 않았습니다. Hobby 플랜에서는 1일 1회보다 잦은 Cron 표현식이 배포 실패를 일으킬 수 있기 때문에 기존 배포 호환성을 우선했습니다.

## 데이터 호환성
기존 Redis 키, NOW Rank, 회원, 방문자, 관리자 비밀번호, 커뮤니티 글/댓글, 정참시News 게시물 키를 변경하지 않았습니다.
새 키만 추가합니다.

- `jjdd:editorial:drafts:v1`
- `jjdd:editorial:schedule:v1`
- `jjdd:editorial:draft-image:v1:*`
