# 정참시 v2.2.16 · 전체 인물 사진 검수

## 1. 전체 DB 사진 검수
- 관리자 메뉴에 `전체 인물 사진 검수`를 추가했습니다.
- 대상은 정참시 현역 정치인 DB 전체 542명입니다.
  - 국회의원 299명
  - 광역단체장 16명
  - 기초단체장 227명
- 버튼 한 번으로 브라우저가 관리자 전용 배치 API를 순차 호출해 전원을 검사합니다.
- 현재 사진 URL 응답, 이미지 MIME, 실제 이미지 크기, 최소 500×500 기준, 검증 출처를 확인합니다.
- 정상 사진은 유지합니다.
- 사진 없음 / 죽은 URL / 저해상도 / 검증 부족 항목만 강제 재검색합니다.
- 재검색 결과가 더 우수한 경우 v5 서버 캐시에 반영합니다.
- 결과는 정상 / 자동 개선 / 검토 필요 / 실패로 분류하고 최근 작업을 Redis에 24시간 보관합니다.

## 2. 사진 경로 통합
- 정참시 roster 542명은 `/api/person-photo?id=...` Vercel 서버 프록시를 사용합니다.
- 국회의원은 대한민국 국회 열린국회정보 공식사진을 우선합니다.
- 지방단체장은 기존 v5 이름 + 직위 + 지역 검색, 원문 문맥 교차검증, 해상도 비교 로직을 유지합니다.
- 문제 사진은 서버에서 캐시를 버리고 한 번 재검색한 뒤에도 실패하면 안전 기본이미지로 종료합니다.
- roster 인물 사진 때문에 브라우저가 Wikidata/Wikipedia/Bing을 직접 호출하지 않습니다.
- `/api/local-photo`는 기존 링크 호환을 위해 `/api/person-photo`와 같은 서버 로직을 사용합니다.

## 3. 보존 사항
- NOW Rank, Redis snapshot, 회원, 결제, 예약게시, 정뮤니티, 정참시News, 브라우저 뒤로가기 history 구조는 변경하지 않았습니다.
- v2.2.15의 `v5-hq-web-search` 사진 캐시 버전을 유지하여 기존 정상 고해상도 캐시를 재사용합니다.
