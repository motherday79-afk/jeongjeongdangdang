# 정참시 v2.2.12

## 변경 사항
- 어드민 정뮤니티 예약/대기 게시물의 작성자 표시명을 게시물별로 수정 가능하게 변경
- 정참시News 작성자는 기존대로 `정참시News 편집부` 고정
- 관리자 발행 정뮤니티 게시물은 내부적으로 운영 게시물(`EDITOR`)로 구분
- 정치인 상세 > RECORD 영역의 빈 네 번째 카드에 `정참시 상세 분석 및 데이터 개선방향 제안` 추가
- FREE/PLUS는 블러 처리된 분석 미리보기 + PRO 가입 안내 표시
- PRO/ADMIN은 현재 관측 데이터 기반 분석 미리보기와 데이터 개선 제안 표시
- 기존 Redis 키, NOW Rank 데이터, 예약 게시 데이터 구조는 유지
