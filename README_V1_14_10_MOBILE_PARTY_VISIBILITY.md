# NOW Rank v1.14.10 · Mobile Party Visibility

## 변경사항
- 모바일 1~300위 목록에서 상세페이지 진입 전 정당명을 바로 확인할 수 있도록 의원명 아래 정당명을 노출합니다.
- 기존 WHY NOW 키워드는 TOP30에만 유지됩니다.
- 따라서 모바일 TOP30은 `순위 / 이름 / 정당 / WHY NOW 키워드`, 31위 이후는 `순위 / 이름 / 정당` 중심의 압축형 목록으로 보입니다.
- 데스크톱의 별도 정당 컬럼과 기존 순위·검색 관심·언론 주목 로직은 변경하지 않았습니다.
- v1.14.9의 장기 순위 변화 추적 및 이전 누적 패치를 모두 유지합니다.
