# v2.2.13 · Photo Search HQ Patch

## 적용 내용
- 정치인 프로필 사진 캐시 키를 갱신해 기존 저해상도/오매칭 캐시를 초기화했습니다.
- 국회 공식 사진 우선 원칙은 유지하되, 공식 사진이 없거나 깨지는 경우 Wikidata/Wikipedia 기반 고해상도 대체 사진을 사용하도록 확장했습니다.
- 국회의원/광역단체장/기초단체장/대통령 등 엔티티 유형과 직위·지역 정보를 함께 사용해 동명이인 오매칭 가능성을 낮추는 검색 점수 로직을 추가했습니다.
- 사진 로딩 실패 시 즉시 기본 이미지로 끝내지 않고, 1회 고해상도 검증 fallback을 시도합니다.

## 기대 효과
- 사진 미노출 인물 감소
- 동명이인 오매칭 감소
- PC 메인/상세의 저해상도 문제 완화

## 주의
- 완전히 동일한 이름을 가진 정치인의 경우, 외부 데이터 자체가 부족하면 기본 이미지가 유지될 수 있습니다.
- 더 높은 완성도를 원하면 서버 측에서 후보 이미지 수집/검수 큐를 운영하는 2차 작업이 가장 좋습니다.
