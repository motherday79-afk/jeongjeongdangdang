# 정정당당 v2.2.1 · 관리자 비밀번호 변경

## 추가 기능
- `/admin.html` 로그인 후 `관리자 보안` 카드에서 비밀번호를 직접 변경할 수 있습니다.
- 현재 비밀번호 확인 → 새 비밀번호(8자 이상) → 새 비밀번호 확인 순서입니다.
- 변경 완료 직후 현재 브라우저의 관리자 세션을 로그아웃하고 새 비밀번호로 다시 로그인합니다.

## 저장 방식
- 최초 관리자 비밀번호는 기존과 같이 Vercel `ADMIN_PASSWORD`를 사용합니다.
- 관리자 화면에서 한 번 비밀번호를 변경하면 새 비밀번호의 **scrypt 해시만 Redis** `jjdd:admin:credential:v1`에 저장되고 이후 로그인에서 우선 사용됩니다.
- 따라서 새 비밀번호 자체는 Redis나 소스코드에 평문으로 저장되지 않습니다.
- `ADMIN_ID`와 `ADMIN_SESSION_SECRET` 구조는 기존 그대로 유지합니다.

## 운영 메모
- 이 패치는 v2.2 LOCAL NOW 전체 기능을 그대로 포함합니다.
- 변경 전에 사용하던 다른 브라우저의 관리자 세션은 최대 기존 세션 만료시간(12시간)까지 남을 수 있습니다. 새로 로그인하는 세션은 즉시 새 비밀번호만 사용합니다.
- 변경한 비밀번호를 분실한 경우 운영자가 Redis의 `jjdd:admin:credential:v1` 키를 삭제하면 Vercel의 `ADMIN_PASSWORD`가 다시 최초 비밀번호로 사용됩니다.
