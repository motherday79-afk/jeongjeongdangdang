# 정참시 v2.2.29

## 관리자 정치인 능력치 편집
- 어드민에 `정치인 능력치 관리` 메뉴 추가.
- 현재 상세페이지의 8축(언론 주목도, 대중 관심도, 디지털 영향력, 대중 반응도, 정책 활동도, 의정 활동도, 정치 영향력, 인지도)을 정치인별 0~100 값으로 수정 가능.
- 관리자 값은 Redis override로 저장되어 Refresh 자동 산출값보다 우선 적용.
- `자동 산출값으로 초기화`로 해당 정치인만 원래 자동값 복귀.

## 메인 화면 관리자 콘텐츠 관리
- 관리자 세션이 살아 있으면 정참시News 기사 상세와 정뮤니티 게시글 상세에 ADMIN 수정/삭제 버튼 노출.
- 정참시News: 분류/제목/요약/본문/대표사진 수정 및 삭제.
- 정뮤니티: 분류/제목/본문 수정 및 게시글+댓글 삭제.
- API에서도 관리자 세션을 재검증하므로 일반 회원에게 권한이 열리지 않음.

## 모바일 어드민 메뉴 동기화
- 모바일 어드민에 전체 메뉴 선택기를 별도로 추가.
- PC와 모바일 메뉴를 동일하게 구성.
- 이전 회귀로 빠졌던 `실시간 급상승 관리`도 복구.
