# v2.2.27 · 설문 보정 실제 적용 연결 수정

## 수정 원인

v2.2.26에서는 서버가 양/음수 보정을 지원했지만, 어드민이 `관리 작업 사유`가 비어 있으면 요청 자체를 차단했습니다. 오류 안내도 별도 상태 영역에만 표시되어 `적용` 버튼이 무반응처럼 보였습니다.

## 수정 내용

- 보정 사유는 선택값으로 변경했습니다. 비어 있으면 `관리자 직접 보정`으로 내부 감사로그에 기록합니다.
- 적용 버튼은 클릭 즉시 `적용 중...` 상태를 표시합니다.
- 서버는 Redis에 HSET/HDEL 후 같은 키를 다시 읽어 보정값이 실제 저장됐는지 검증합니다.
- 검증 성공 후 어드민에 `실제 N표 + 보정 ±N = 메인 N표`를 표시합니다.
- 공개 API는 기존처럼 최종 집계값만 반환합니다.

## 목표 동작

박주민 문항의 실득표가 1표이고 관리자 보정란에 10을 입력한 뒤 `적용`을 누르면, 어드민에 `실제 1표 + 보정 +10 = 메인 11표`가 표시되고 공개 설문 API의 해당 문항 counts도 11이 됩니다.
