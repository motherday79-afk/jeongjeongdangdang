# 정참시 v2.2.21 · 실시간 급상승 운영제어 + ㅈㅊㅅ 브랜드 마크

## 실시간 급상승 TOP10 어드민 관리
- 어드민 메뉴에 `실시간 급상승 관리`를 독립 메뉴로 추가했습니다.
- 메인 오른쪽 사이드의 `실시간 급상승 TOP10` 노출 ON/OFF를 저장할 수 있습니다.
- `자동 산출` 모드에서는 기존처럼 직전 게시 Refresh 대비 실제 상승폭으로 TOP10을 계산합니다.
- `운영자 편집` 모드에서는 1~10위 각각을 현재 게시된 정치인 542명에서 이름·정당·지역으로 검색해 지정할 수 있습니다.
- 각 슬롯의 상승폭은 비워두면 실제 갱신값을 사용하고, 숫자를 입력하면 표시 상승폭을 운영자가 조정할 수 있습니다.
- 운영자 편집에서 비어 있는 슬롯은 실제 자동 급상승 순위로 보충되어 빈 카드가 생기지 않습니다.
- 동일 정치인을 여러 순위에 중복 저장하지 못하도록 검증합니다.
- `현재 자동 TOP10으로 채우기` 버튼으로 현재 자동 결과를 편집 초깃값으로 가져올 수 있습니다.

## 메인 로고 마크
- 기존 막대 그래프형 마크를 제거했습니다.
- 민트 그라데이션 배경에 흰색 `ㅈㅊㅅ` 모노그램을 적용했습니다.
- 하단 비대칭 말풍선 꼬리와 작은 LIVE 점을 넣어 정참시의 참여·대화·실시간성을 표현했습니다.
- 기존 `정참시 / 정치에 참여할 시간` 워드마크는 유지해 브랜드 인지성을 보존했습니다.
