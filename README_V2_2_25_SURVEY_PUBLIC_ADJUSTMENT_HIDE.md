# v2.2.25 · 설문 관리자 보정 공개표시 제거

- 메인 정참시 자체 설문조사에서 `관리자 보정 포함` 문구를 완전히 제거했습니다.
- 공개 `/api/site-settings` 응답에서도 관리자 보정 여부, 보정값, 실응답 원본값을 제거했습니다.
- 일반 사용자에게는 문항별 최종 집계값(`counts`), 최종 총응답(`total`), 본인 투표 여부만 전달됩니다.
- 관리자 화면에서는 실응답, 무효응답, 관리자 보정값, 보정 사유 및 감사기록을 기존대로 유지합니다.
- 관리자 보정은 사유 기록을 계속 필수로 하며 운영 기록은 내부에서만 확인할 수 있습니다.
- v2.2.23의 562명 비파괴 사진 복구 구조, v2.2.24의 설문 어뷰징 관리, v2.2.21 민트 `ㅈㅊㅅ + LIVE` 로고를 그대로 유지합니다.
