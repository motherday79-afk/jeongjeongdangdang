# NOW Rank v1.14 · 실시간 급상승 TOP10

## 변경 사항
- 메인 오른쪽 사이드바 순서: NOW ISSUE → 실시간 급상승 TOP10 → 정정뉴스
- 급상승 TOP10은 현재 순위 자체가 아니라 직전 게시 스냅샷 대비 `changeRefresh` 상승폭을 기준으로 전체 의원 299명에서 선발
- TOP30 밖의 저순위 의원도 상승폭이 크면 노출
- 각 행에 현재 순위, 정당, 가능한 경우 WHY NOW 대표 키워드, 직전→현재 순위 표시
- 직전 비교 스냅샷이 없으면 임의 값 생성 없이 데이터 축적 안내
- 모바일에서도 NOW 요약 흐름 안에 동일 카드를 이동해 노출

## 데이터 원칙
`changeRefresh = previousRank - currentRank`
양수일수록 직전 게시 대비 많이 상승한 의원입니다.
