# NOW Rank v1.14.8 · Roster Identity Hotfix

## 핵심 수정
- 현역 roster 5석 교체 반영
  - id 27: 이진숙 · 국민의힘 · 대구 달성군
  - id 203: 윤용근 · 국민의힘 · 충남 공주시부여군청양군
  - id 210: 김의겸 · 더불어민주당 · 전북 군산시김제시부안군갑
  - id 211: 박지원 · 더불어민주당 · 전북 군산시김제시부안군을
  - id 254: 김성범 · 더불어민주당 · 제주 서귀포시
- 현역 299명 + 강릉 공석 1석 구조 유지
- 내부 수집/스코어/트래픽/이력의 기본키를 의원명에서 `memberId` (`id:<숫자>`) 우선으로 전환
- 동명이인 박지원 의원 2명을 id 26 / id 211로 완전히 분리
- 동명이인 이름만으로 얻는 NAVER Name Pulse 검색량은 개인별 점수에 중복 반영하지 않음
- 동명이인 뉴스/포털 수집은 지역구·지역 단서를 함께 사용
- 상세페이지 7일 순위 이력 API도 `id + name`으로 조회
- 공개 스냅샷 schemaVersion 3 + rosterVersion 검증 추가
- 구 roster가 남은 기존 브라우저 캐시는 v1.14.8 캐시 키에서 자동 배제
- 이전 roster 스냅샷으로의 롤백 차단
- 동명이인 프로필 사진은 국회 데이터에서 지역구 단서로 식별될 때만 사용하고, 식별 실패 시 잘못된 사진 대신 기본 이미지를 표시

## 배포 후 반드시 1회 실행
1. ZIP 전체 내용을 GitHub 저장소 루트에 덮어쓰기
2. Vercel Production 배포 완료 확인
3. `/admin.html`에서 NOW Rank Refresh 전체 실행
4. 결과 검토 후 게시

배포 직후 아직 새 Refresh/게시를 하지 않은 상태에서는 기존 Redis current가 이전 roster를 담고 있으므로 공개 메인은 새 roster와 일치하는 게시본을 기다린다는 안내를 표시할 수 있습니다. 이는 의도된 안전장치입니다.

첫 v1.14.8 게시에서는 모델/roster 기준선이 변경되므로 직전 순위 변화값을 억지로 승계하지 않습니다. 그 다음 게시부터 새 roster 기준 변화폭이 정상 누적됩니다.
