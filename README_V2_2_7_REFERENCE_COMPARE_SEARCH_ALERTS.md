# 정참시 v2.2.7 — Reference Compare + Search + Alerts

## 변경 사항

- 대통령과 현 정부 주요 인사는 NOW Rank 순위 밖에 유지합니다.
- 대통령 상세의 8개 비교지표를 실제 레이더 좌표로 표시하고 비교분석 검색 대상에 포함했습니다.
- 현 정부 주요 인사 상세에도 8개 비랭킹 참고 비교지표와 레이더를 추가했습니다. 이 값은 공식 직무평가가 아니라 공개 이력·현재 직책을 구조화한 참고 프로필이며 순위 산정에는 반영되지 않습니다.
- 비교분석에서 국회의원/광역단체장/기초단체장뿐 아니라 대통령/현 정부 주요 인사를 함께 선택할 수 있습니다.
- 상단 돋보기 버튼을 실제 통합검색으로 연결했습니다. 이름·정당·지역·기관·직위를 검색하고 바로 상세로 이동합니다.
- 상단 알림 버튼은 로그인 회원의 ON/OFF 계정 설정을 Redis 사용자 프로필에 저장합니다. 기본값은 OFF입니다. 현재 버전은 수신 선호 설정 저장 단계이며 브라우저 푸시 발송 채널 자체를 새로 구현한 것은 아닙니다.
- 대통령 메인 카드와 상세에서 OUT OF RANK 배지를 제거하고 오늘 기준 남은 임기를 동적으로 표시합니다. 기준: 2025-06-04 취임, 헌법상 5년 임기, 표시 종료일 2030-06-03.

## 배포

기존 저장 데이터와 NOW Rank 스냅샷은 유지됩니다. 랭킹 모델을 바꾸지 않았으므로 배포 후 Refresh는 필수가 아닙니다.
