# v2.2.26 · 설문 양방향 보정 + 관리자 버전 표시 복구

- 정참시 자체 설문조사 관리자 보정을 음수(-) 감산 / 양수(+) 가산으로 명확히 노출
- 각 문항에 `-10 / -1 / 직접입력 / +1 / +10 / 적용` 컨트롤 추가
- 직접입력은 -1,000,000 ~ +1,000,000 범위 지원
- 양수 보정 예: 실응답 120 + 관리자 보정 +30 = 메인 노출 150
- 음수 보정 예: 실응답 120 + 관리자 보정 -20 = 메인 노출 100
- 보정값/사유는 기존처럼 어드민 감사기록에만 유지
- 공개 화면에는 최종 집계값만 노출하는 v2.2.25 정책 유지
- 어드민 브라우저 제목 / 상단 BUILD 배지 / Refresh 완료 문구를 v2.2.26으로 동기화
