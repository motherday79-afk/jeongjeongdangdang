# 정정당당 NOW Rank v1.6.1 · Relative Display

## 이번 수정 범위
수집 원천, RAW NOW Score 산식, 순위 결정 로직은 변경하지 않았습니다.

변경한 것은 **화면에 보이는 NOW 지수와 5각형 5개 축의 표시 스케일**뿐입니다.

- `rawScore`: 기존 실측 원점수 그대로 보존
- `rank`: 기존 RAW 점수 기반 순위 그대로 유지
- `score`: 전체 현역 의원 스냅샷 안에서의 상대 위치 + 원신호 강도를 혼합한 표시지수
- `metrics`: 5개 축 각각을 같은 축의 전체 의원 분포 안에서 상대 정규화
- 실제 신호가 0인 축은 0 유지
- 동일 원점수는 동일 표시점수 처리
- 기본점수를 일괄 가산하지 않음

## 목적
기본점수 제거 후 대부분 C/D에 몰리고 레이더 차트가 중앙에 수축되어 비교가 어려운 문제를 해결합니다.
상대적으로 강한 의원은 차트가 충분히 펼쳐지고, 약한 의원은 여전히 작게 보여 비교 가능성을 높입니다.

## 기존 게시 스냅샷 대응
`index.html`에도 동일한 상대 표시 변환을 넣었습니다. 따라서 배포 직후 Redis의 기존 v1.6 스냅샷도 화면에서 상대 표시로 변환됩니다.
다음 관리자 Refresh → Publish부터는 서버가 v1.6.1 상대 표시점수를 스냅샷에 직접 저장합니다.
