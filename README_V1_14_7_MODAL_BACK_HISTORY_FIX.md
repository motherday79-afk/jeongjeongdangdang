# NOW Rank v1.14.7 — 상세 팝업 뒤로가기 수정

- 국회의원 상세 팝업을 열 때 같은 페이지 안에 History API 상태를 1개 추가합니다.
- 브라우저/안드로이드 뒤로가기를 누르면 사이트를 이탈하지 않고 상세 팝업만 닫히며 기존 1~300 리스트와 스크롤 위치가 그대로 남습니다.
- X 버튼/바깥 영역 닫기도 History 상태를 함께 정리합니다.
- 브라우저 앞으로가기를 하면 해당 상세 팝업을 다시 복원할 수 있습니다.
- 대통령/정부인사 공통 상세 팝업에도 같은 동작을 적용했습니다.
- NOW Rank 데이터, 수집, 캐시, 정렬, 스타일은 변경하지 않았습니다.
