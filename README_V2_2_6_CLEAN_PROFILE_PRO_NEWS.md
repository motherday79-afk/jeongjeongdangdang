# 정참시 v2.2.6 · Clean Profile + PRO News Publisher

## 변경사항

- PC/모바일 정치인 목록과 상세에서 `REAL`, `REAL DATA`, `국회 공식 프로필` 등 반복 배지를 제거했습니다.
- 기본정보는 그대로 유지하되 출처 강조 문구를 카드마다 반복 노출하지 않도록 정리했습니다.
- 정정뉴스를 Redis 기반 실제 작성형 뉴스로 전환했습니다.
- 정정뉴스 작성 권한은 PRO / ADMIN만 허용합니다. 관리자 세션도 운영자 권한으로 발행할 수 있습니다.
- 대표 사진을 JPG/PNG/WEBP로 첨부할 수 있습니다. 브라우저에서 1200×675(16:9) 중앙 크롭 후 WEBP/JPEG로 최적화하며 최대 약 1.2MB만 서버가 허용합니다.
- 뉴스 목록, 우측 메인 뉴스, 기사 상세의 이미지 영역은 `object-fit: cover` + 고정 비율로 처리해 이미지가 레이아웃 밖으로 넘치지 않습니다.
- 실제 발행 뉴스가 1개 이상 존재하면 샘플 뉴스 대신 발행 뉴스만 표시합니다. 발행 뉴스가 없을 때만 기존 샘플 화면을 유지합니다.
- 기존 NOW Rank, LOCAL NOW, 방문자 통계, 커뮤니티, PLUS, 관리자 기능과 Redis 키는 유지합니다.

## 운영 메모

사이트 회원의 PRO 등급은 기존 관리자 회원관리에서 지정할 수 있습니다. 관리자(`jjdd_admin`)로 로그인된 브라우저도 정정뉴스 발행 권한을 가집니다.
