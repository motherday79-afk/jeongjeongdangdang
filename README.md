# 정참시 v2.2.19 · 사이드바 NOW ISSUE 복구 + 방문자 일마감

v2.2.18의 사진 검수 자동복구/직접복구 기능을 그대로 유지하면서, 메인 오른쪽 사이드의 NOW ISSUE가 사라지는 저장상태를 복구하고 방문자 집계를 `전일까지 확정 누적 + 오늘 방문` 구조로 변경했습니다.

- 오른쪽 사이드: NOW ISSUE → 설문조사 → 실시간 급상승 → 정참시News
- 기존 저장상태 때문에 숨겨진 NOW ISSUE는 배포 후 1회 자동 ON 복구
- KST 자정에 전날 누적값 확정 및 새 날짜 TODAY 시작
- 자정 Cron 지연/실패 시 첫 방문/통계 요청이 자동 일마감 보완
- 어드민 초기화는 전일 확정 누적을 건드리지 않고 오늘 보정값만 초기화

자세한 변경점은 `README_V2_2_19_SIDEBAR_VISITOR_DAILY_FIX.md`를 참고하세요.
