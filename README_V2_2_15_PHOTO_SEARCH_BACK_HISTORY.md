# 정참시 v2.2.15

## 1. 지방단체장 사진 방식 변경
- `photoVerified + officialPhoto`가 있으면 기존 검증 사진을 최우선 사용합니다.
- 그 외 지방단체장은 브라우저가 외부 사이트를 직접 검색하지 않고 `/api/local-photo?id=...`를 호출합니다.
- 서버에서 이름 + 직위 + 지역으로 검색어를 만들고 Kakao Image Search(키가 있는 경우) + Bing Images를 병행합니다.
- 검색결과 제목/설명 또는 원문 페이지에서 이름과 직위/지역 단서를 확인해 동명이인 가능성을 낮춥니다.
- 해상도와 출처 신뢰도를 함께 점수화해 500px 이상 후보를 우선합니다.
- 최종 원본은 서버가 프록시하고 CDN 캐시를 사용합니다. 깨진 URL은 캐시를 폐기하고 한 번 재검색합니다.
- 검색 캐시 버전을 v5로 올려 이전 실패/저해상도 캐시를 사용하지 않습니다.

## 2. 뒤로가기
- 메인 5개 메뉴 이동 상태를 History API에 기록합니다.
- 정참시News 기사 열기/닫기를 브라우저 history와 연결했습니다.
- 정뮤니티 게시물 열기/닫기를 브라우저 history와 연결했습니다.
- 정치인/대통령/정부 상세 모달의 기존 history 로직과 통합했습니다.
- 예: NOW → 정뮤니티 → 게시물 상세에서 브라우저 뒤로가기 = 정뮤니티 목록, 다시 뒤로가기 = NOW.

## 3. 보존 사항
- NOW Rank 데이터/Redis snapshot/회원/예약게시/PRO 상세분석은 변경하지 않았습니다.
- 외부 이미지 검색 실패 시 기존 안전 기본이미지 fallback은 마지막 단계로 유지합니다.
