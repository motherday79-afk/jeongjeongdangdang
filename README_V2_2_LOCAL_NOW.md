# 정정당당 v2.2 · LOCAL NOW

## 이번 업데이트의 핵심
정정당당 NOW Rank의 대상을 국회의원에서 지방자치단체장까지 확장했습니다.

- 국회의원 현역 299명
- 광역단체장 16명
- 기초단체장 227명
- 현역 정치인 총 542명
- 기존 강릉시 국회의원 공석 1석은 국회의원 카테고리의 공석 행으로 유지

지방단체장 기준 명단은 2026년 제9회 전국동시지방선거 이후 현직 기준으로 분리 저장하며, 국회의원 명단과 같은 `memberId` 우선 식별 체계를 사용합니다.

## 메인 NOW Rank 카테고리
기존 `전체 / 검색 관심 / 언론 주목` 메인 탭을 아래 구조로 변경했습니다.

- 전체: 국회의원 + 광역단체장 + 기초단체장 542명을 함께 비교한 종합 NOW Rank
- 국회의원: 국회의원 직군 내 순위
- 광역단체장: 광역단체장 직군 내 순위
- 기초단체장: 기초단체장 직군 내 순위

`검색 관심`, `언론 주목` 수치는 사라지는 것이 아니라 각 인물 상세의 분석 지표로 유지됩니다.

## WHY NOW 키워드 카테고리
실시간 WHY NOW도 독립적으로 아래 네 범위를 선택할 수 있습니다.

- 전체
- 국회의원
- 광역단체장
- 기초단체장

각 선택 범위의 상위 인물을 기준으로 20~25개의 설명 가능한 사건성 키워드를 구성합니다.

## 지방단체장 사진 안전정책 — 중요
사진 정확도는 데이터 숫자보다 보수적으로 처리합니다.

1. 지방정부 공식 홈페이지 등 공식 출처에서 해당 인물임이 확인된 사진만 `photoVerified=true`로 등록합니다.
2. 이름만으로 Wikipedia/Wikidata/검색 결과 사진을 추정해서 사용하지 않습니다.
3. 공식 사진이 아직 검증되지 않은 인물은 다른 동명이인 사진을 보여주는 대신 안전 기본 인물 이미지를 표시합니다.
4. `data/local_leaders.json`의 `officialPhoto`, `officialProfileUrl`, `photoVerified`를 통해 이후 공식사진을 순차적으로 확정할 수 있습니다.
5. 관리자 Refresh 미리보기에서 `공식사진 검증 / 안전 기본이미지` 수를 확인할 수 있습니다.

초기 v2.2에서 지방단체장의 기본이미지가 보이는 것은 오류가 아니라 잘못된 인물 사진 노출을 방지하기 위한 의도된 안전동작입니다.

## 동명이인·외부 동명이인 신호 안전장치
지방단체장은 배우·기업인 등 정치권 밖의 동명이인까지 고려해 이름 단독 신호를 최대한 배제합니다.

- NAVER Name Pulse: `이름 + 공식 직책`으로 조회
- X: `이름 + 공식 직책 + 관할 지역`을 결합
- Google Trends: 이름과 함께 직책/관할 단서가 확인될 때만 귀속
- 뉴스/포털/YouTube/BIG KINDS: 직책·지역 문맥이 포함된 정치 문맥 검증을 통과한 항목만 반영

정확하게 식별할 수 없는 데이터는 순위에 억지로 넣지 않는 것을 기본 원칙으로 합니다.

## 데이터·순위 구조
- `data/local_leaders.json`: 광역·기초단체장 원본
- `lib/political_roster.js`: 국회의원 + 지방단체장 통합 정치인 roster
- `lib/political_entity.js`: 직책/지역/동명이인 검색 문맥
- `lib/score.js`: 전체순위(`overallRank`)와 직군순위(`categoryRank`) 동시 계산
- Public snapshot schema: v4
- Roster version: `2026-08-15-national-local-v1`
- Rank model: `political-entity-now-v2-local-2026`

PLUS의 관심 정치인 저장도 같은 정치인 ID를 사용하므로 지방단체장까지 저장할 수 있습니다.

## 배포 후 반드시 할 일
이번 버전은 roster와 순위 모델이 바뀌므로 기존 공개 스냅샷을 그대로 재사용하지 않습니다.

1. ZIP 전체 내용을 GitHub 저장소 루트에 덮어씁니다.
2. Vercel Production 배포 완료를 기다립니다.
3. `/admin.html`에서 `NOW Rank 새로고침`을 실행합니다.
4. 542명 수집 결과와 `지방단체장 공식사진 / 사진 안전 기본이미지` 상태를 확인합니다.
5. 이상이 없으면 `게시`합니다.

첫 v2.2 게시에서는 이전 모델/명단과 직접 순위 변동을 비교하지 않습니다. 첫 게시를 새로운 기준선으로 삼고, 그 다음 게시부터 정상적인 전체·직군 순위 변화가 기록됩니다.
