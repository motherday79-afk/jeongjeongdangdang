# 정정당당 v2.2.3 · LOCAL COMMUNITY

이번 빌드는 v2.2.2 Redis 10MB 핫픽스와 v2.2.1 관리자 비밀번호 변경 기능을 그대로 유지하면서, 지방자치단체장/메인 UX 요청 5가지를 반영한 전체 배포본입니다.

## 1. 지방단체장 Name Pulse 보강
- 광역·기초단체장은 `이름+공식직위` 키워드를 우선 조회합니다.
- 직위 결합 키워드가 NAVER 광고 키워드 도구에서 정확히 반환되지 않을 경우, 전체 542명 roster에서 동명이인이 아닌 인물에 한해 이름 단독 검색량을 72% 신뢰도로 보조 반영합니다.
- 동명이인은 이름 단독 fallback을 사용하지 않아 다른 인물의 검색량이 섞이지 않게 했습니다.
- 관리자 상세 감사 화면에서 실제 Name Pulse 조회어를 확인할 수 있습니다.

## 2. 지방단체장 직위 표시 정리
- 광역단체장은 메인 순위에서 `경기도 경기도지사`처럼 중복 표시하지 않고 `경기도지사`, `울산광역시장`처럼 직위만 표시합니다.
- 기초단체장은 동명 자치구 구분을 위해 `서울특별시 · 중구청장`처럼 광역지역 + 직위 형태로 간결하게 표시합니다.
- `구청장/시장/군수` 직위 문자열의 불필요한 공백도 제거했습니다.

## 3. 광역·기초단체장 사진
- 기존의 '검증 전 무조건 기본이미지'에서 한 단계 확장했습니다.
- roster에 직접 검증된 지방정부 공식 사진이 있으면 최우선 사용합니다.
- 직접 사진이 없는 경우 대한민국시도지사협의회(광역), 대한민국시장군수구청장협의회(기초)의 공식 회원 페이지에서 이름과 직위/지역이 함께 확인되는 사진만 서버에서 찾아 프록시합니다.
- 이름만으로 Wikipedia/일반 웹 사진을 추정하지 않습니다.
- 공식 협의회에서 사진을 확인하지 못하면 기존 안전 기본이미지로 자동 fallback 합니다.

## 4. 현재 접속 / 오늘 방문 / 누적 방문
- PC와 모바일 메인 상단에 방문 현황 스트립을 추가했습니다.
- 현재 접속: 최근 5분 안에 활동한 익명 브라우저 수
- 오늘 방문: KST 기준 오늘의 익명 고유 브라우저 수
- 누적 방문: 기능 도입 이후 익명 고유 브라우저 수
- Redis HyperLogLog + 5분 ZSET을 사용해 방문자가 늘어나도 키가 폭증하지 않도록 구성했습니다.
- 별도 환경변수는 필요하지 않으며 기존 Redis를 사용합니다.

## 5. 정정LIVE → 커뮤니티
- PC 상단 메뉴의 `정정LIVE`를 제거하고 `커뮤니티`로 교체했습니다.
- 모바일 하단 메뉴의 LIVE도 `커뮤니티`로 교체했습니다.
- 카테고리: 자유토론 / 정책 / 지역정치 / 질문
- 게시글 목록/상세/댓글을 지원합니다.
- 글과 댓글 작성은 정정당당 로그인 회원만 가능합니다.
- 게시글과 댓글은 기존 Redis에 저장됩니다.
- 작성 빈도 제한을 적용했습니다.
- 커뮤니티 반응은 NOW Rank 점수에 직접 반영하지 않습니다.

## 배포 후
1. 전체 ZIP을 기존 Vercel 프로젝트에 덮어써 배포합니다.
2. `/admin.html` 로그인 후 `NOW Rank 새로고침`을 새로 실행합니다.
3. Refresh 완료 후 광역/기초단체장 Name Pulse 값을 확인하고 게시합니다.
4. 메인에서 지방단체장 사진, 방문자 카운터, 커뮤니티 메뉴를 확인합니다.

방문자 통계는 이 버전 배포 시점부터 집계되며 과거 방문 수를 소급 생성하지 않습니다.
