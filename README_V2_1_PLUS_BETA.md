# 정정당당 v2.1 PLUS Beta

## 이번 빌드
- FREE / PLUS / PRO / ADMIN 권한 구조 유지
- PLUS 실제 기능 활성화
  - 관심 의원 최대 30명 저장
  - 관심 이슈 최대 30개 저장
  - MY > PLUS 대시보드 / 내 관심 브리핑
  - 30일 / 1년 NOW Rank 장기 히스토리
  - 정치인 비교 기능 PLUS 권한 적용
- FREE는 24시간 / 7일 순위 이력까지 이용
- 의원 상세에서 관심 의원 저장 버튼 제공
- WHY NOW에서 관심 이슈 저장 버튼 제공
- PLUS 월 5,000원 결제하기 버튼 추가
- CMS는 아직 연결하지 않음
  - `/api/billing/checkout` 계약을 미리 생성
  - 버튼 클릭 시 실제 결제 없이 PENDING_PROVIDER 결제의사 기록만 생성
  - 향후 CMS 연동 시 이 endpoint 내부만 실제 checkout 흐름으로 교체할 수 있도록 분리
- PRO는 준비중 유지

## 테스트 방법
1. FREE 계정 로그인
2. 정치인 비교 / 30일·1년 히스토리 / 관심 저장 클릭 시 PLUS 안내 확인
3. MY > 멤버십 > PLUS 구독하기 클릭
   - 실제 결제는 발생하지 않으며 CMS 준비중 문구가 나와야 함
4. `/admin.html`에서 테스트 계정을 PLUS로 변경
5. 다시 로그인 또는 MY 새로고침
6. 의원 상세에서 관심 의원 저장
7. WHY NOW에서 관심 이슈 저장
8. MY > PLUS 대시보드에서 저장내용과 관심 브리핑 확인
9. 30일 / 1년 히스토리 확인
10. 정치인 비교 기능 확인

## 결제 연동 전에 해야 할 일
- CMS 사업자/PG 흐름 확정
- 실제 결제 API / webhook / 결제상태 검증
- 결제 성공 시 서버에서만 FREE -> PLUS 승급
- 해지/연체/환불 시 등급 회수 정책
- 결제·환불 약관 최종 법률검토
- USER_SESSION_SECRET / USER_DATA_ENCRYPTION_KEY Production 설정

## 데이터 원칙
관심 의원 저장은 '지지'가 아니라 사용자가 추적할 대상을 저장하는 기능으로 표시합니다. 관심 정당과 정치 관련 개인화 데이터의 법적 처리 방식은 정식 운영 전 법률 자문을 반영해 최종 확정해야 합니다.
