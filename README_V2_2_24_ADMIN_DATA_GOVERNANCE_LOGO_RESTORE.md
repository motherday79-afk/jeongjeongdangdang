# 정참시 v2.2.24 · 관리자 데이터 거버넌스 + 설문 어뷰징 관리 + 로고 복원

## 1. 관리자 데이터 거버넌스 원칙
사용자 입력/투표/참여형 기능은 운영자가 결과만 보는 것으로 끝내지 않고, 운영 데이터의 유효성까지 관리할 수 있도록 구성합니다.

이번 버전의 정참시 자체 설문조사에는 다음 기능을 추가했습니다.

- 유효 응답 / 무효 응답 분리 조회
- 회원별 설문 응답 무효화 및 복구
- 응답 회원의 아이디·닉네임·가입일·지역·선호정당·계정상태 확인
- 설문 응답 화면에서 회원 계정 즉시 정지/해제
- 특정 문항의 현재 유효 응답 일괄 무효화
- Redis 응답 hash를 기준으로 실응답 재집계
- 현재 설문의 유효/무효 응답 및 관리자 보정 전체 초기화
- 문항별 관리자 보정값 설정/제거
- 관리자 보정은 사유 기록 필수이며, 0이 아닌 보정이 존재하면 메인 설문 결과에 `관리자 보정 포함` 문구 표시
- 관리 작업 감사로그 최근 100건 Redis 보존

관리자 보정은 숨겨진 결과 조작용이 아니라 운영상 정정값을 실제 회원 응답과 분리해 관리하기 위한 구조입니다. 메인 표시값에는 보정 여부를 명시합니다.

## 2. 회원 어뷰징 대응
- 회원관리에서 ACTIVE / SUSPENDED 상태 전환 가능
- SUSPENDED 전환 즉시 기존 로그인 세션 무효화
- SUSPENDED 회원은 새 로그인 및 기존 인증 모두 차단
- 설문 응답 관리 화면에서도 응답자 계정을 바로 정지/해제 가능

## 3. 정참시 로고 복원
v2.2.21에서 확정한 로고를 그대로 복원했습니다.

- 민트 그라데이션 말풍선형 아이콘
- 흰색 `ㅈㅊㅅ` 모노그램
- 우측 상단 흰색 LIVE 포인트
- 모바일용 축소 규격 포함

v2.2.23의 전체 사진 회귀 복구 / 비파괴 검수 기능은 그대로 유지합니다.
