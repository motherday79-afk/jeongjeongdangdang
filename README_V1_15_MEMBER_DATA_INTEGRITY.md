# NOW Rank v1.15 · Member Data Integrity

## 핵심 수정
- 상세페이지 의원 사진도 대한민국 국회 공식 사진을 최우선 사용합니다.
- 국회의원 사진은 이름만으로 Wikipedia/Wikidata를 추정하지 않습니다. 공식 식별 실패 시 안전한 기본 이미지로 표시합니다.
- 사진 캐시는 이름이 아닌 의원 ID 기준으로 새로 분리했으며, 기존 오염 가능 캐시는 자동으로 사용하지 않습니다.
- 열린국회정보 ALLNAMEMBER를 의원 기본정보 검증 레이어로 추가했습니다.
- `GTELT_ERACO`의 실제 당선 대수를 배열로 파싱해 초선/재선/다선을 자동 계산합니다.
  - 예: 제19대 + 제22대 = 재선 (19·22대)
  - 연속 당선 여부는 선수 계산에 영향을 주지 않습니다.
- 동명이인은 이름 + 지역구/정당 맥락으로 분리합니다.
- 메인 NOW RANK 소개문을 투자/서비스 설명용 문구로 개편했습니다.

## 새 API
- `/api/member-master`
- 공식 국회 의원정보를 정규화해 반환하고 Redis/Edge에 장기 캐시합니다.
- `ASSEMBLY_OPEN_API_KEY`는 선택 환경변수입니다. 미설정 시 공개 endpoint를 먼저 시도합니다.

## 배포
ZIP 전체를 저장소 루트에 덮어쓰고 Vercel 배포합니다.
NOW Rank 점수/게시 스냅샷 구조는 변경하지 않았으므로 이 패치만으로 별도 Refresh는 필수 아닙니다.
