# v2.2.28 · TOP30 한 줄 뉴스 보장

## 수정 배경
v2.2.20 이후 순위 카드의 이름 아래 한 줄 뉴스가 최근 6시간 headline 중심으로만 선택되어, NOW Rank 상위권이어도 최근 6시간 제목이 비면 한 줄 뉴스가 공란이 되는 문제가 있었습니다.

## 변경 사항
- 한 줄 뉴스 후보 범위를 6시간 → 24시간/7일 최근기사 → 전체 정치뉴스 코퍼스 → 직전 정상 한 줄 순으로 확장했습니다.
- Refresh 시 서버가 `rankHeadline`을 확정해 스냅샷에 저장합니다.
- 공개 스냅샷에도 `rankHeadline`, 출처, 시각, 후보 유형을 전달합니다.
- TOP30은 한 줄 뉴스 공란을 허용하지 않습니다.
- 실제 기사 후보를 확보하지 못한 극단적인 경우에만 `최근 주요 뉴스 확인 중` 안전 문구를 사용합니다.
- 브라우저는 서버 확정 `rankHeadline`을 최우선 사용하며, 구버전 스냅샷에는 클라이언트 후보 선택 로직으로 호환합니다.
- 기존 6시간 뉴스 카운트/WHY NOW 계산 의미는 유지하고, 별도의 `headlineCandidates`만 최대 7일 범위로 추가합니다.

## 검증
- 김민석: 6시간 headline 0건 + 36시간 전 후보 → 한 줄 선택 성공
- 정청래: 개인 6시간 headline 0건 + 전체 정치뉴스 후보 → 한 줄 선택 성공
- 31명 모의 스냅샷 TOP30 → 공란 0명
- public snapshot 전달 확인
