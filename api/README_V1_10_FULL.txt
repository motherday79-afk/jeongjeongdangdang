정정당당 NOW Rank v1.10 · Name Pulse Probe FULL

이 ZIP은 v1.8 Audit Console 전체 파일 + NAVER Search Ads Name Pulse 테스트 API를 합친 전체 교체용 패키지입니다.

사용 방법
1) ZIP 압축 해제
2) 압축 안의 파일/폴더 전체를 GitHub 저장소 루트에 덮어쓰기
3) Commit
4) Vercel 배포 완료 대기
5) Vercel 환경변수 확인:
   NAVER_AD_ACCESS_LICENSE
   NAVER_AD_SECRET_KEY
   NAVER_AD_CUSTOMER_ID
6) 관리자 로그인 후 아래 주소 접속:
   https://<현재도메인>/api/admin/name-pulse

기본 테스트 인물
김민석, 정청래, 한동훈, 서미화, 김종민, 천하람

주의
- 이 버전의 Name Pulse는 테스트 전용입니다.
- 아직 NOW Rank 점수/순위에는 검색광고 데이터를 반영하지 않습니다.
- 실제 비밀키는 ZIP에 포함되어 있지 않습니다.
