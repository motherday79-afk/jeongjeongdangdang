# 정정당당 v2.0.1 · Simple ID Login

## 변경 사항

- 로그인 기준을 이메일에서 일반 아이디로 변경
- 신규 회원가입 필수값: 아이디 / 닉네임 / 이메일 / 비밀번호
- 아이디: 영문, 숫자, 밑줄(_) 4~20자
- 아이디 중복은 대소문자와 무관하게 처리 (`Apple12`와 `apple12`는 같은 아이디)
- 이메일은 필수 계정정보로 계속 보관하지만 신규 로그인 화면에서는 입력하지 않음
- 비밀번호: 대문자/소문자/숫자/특수문자 조합 강제 없이 8자 이상 128자 이하
- 비밀번호는 기존과 동일하게 scrypt 단방향 해시 저장
- 관리자 회원목록에 아이디 표시 및 아이디 검색 지원
- MY 프로필에 아이디 표시
- v2.0에서 이미 만든 기존 테스트 계정은 이메일 로그인 호환 유지
- 기존 계정은 MY 프로필에서 아이디를 한 번 설정한 뒤 이후 아이디 로그인 가능
- 회원 탈퇴 시 아이디 인덱스와 이메일 인덱스를 함께 삭제
- 이용약관/개인정보처리방침 초안에 아이디 필수수집 구조 반영

## 배포 후 테스트

1. 신규 회원가입에서 `apple12` 같은 아이디를 생성합니다.
2. 비밀번호는 조합 조건 없이 8자 이상으로 가입되는지 확인합니다.
3. 로그아웃 후 이메일이 아니라 아이디로 로그인합니다.
4. 같은 아이디의 대소문자 변형으로 중복가입이 차단되는지 확인합니다.
5. 같은 이메일 중복가입이 차단되는지 확인합니다.
6. 관리자 > 회원/등급 관리에서 아이디가 표시되고 검색되는지 확인합니다.
7. v2.0 기존 계정이 있다면 기존 이메일로 로그인한 뒤 MY에서 아이디를 1회 설정합니다.

## 비밀번호 정책

사용 편의성을 위해 조합 강제 규칙은 두지 않습니다. 서버의 비밀번호 비교는 일반적인 보안 원칙대로 입력한 문자열이 정확히 일치해야 하며, 저장은 평문이 아니라 scrypt 해시를 사용합니다.
