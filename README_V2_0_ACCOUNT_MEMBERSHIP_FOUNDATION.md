# 정정당당 v2.0 · Account & Membership Foundation

## 이번 빌드의 범위

이번 버전은 유료 기능을 억지로 한 번에 넣지 않고, 앞으로 PLUS/PRO를 안정적으로 붙이기 위한 회원 기반을 먼저 완성하는 1차 빌드입니다.

- 이메일 + 비밀번호 + 닉네임 회원가입
- 로그인 / 로그아웃 / 세션 유지
- 회원 등급: `FREE / PLUS / PRO / ADMIN`
- 신규 가입은 항상 `FREE`
- 관리자 콘솔에서 회원 등급 직접 변경 가능
- MY 페이지 실제 계정 데이터 연결
- 선택적 `관심 정당` 설정
- 관심 정당은 별도 민감정보 동의가 있을 때만 저장
- 관심 정당 저장 시 AES-256-GCM 암호화
- 비밀번호는 scrypt 단방향 해시 저장
- 회원 탈퇴 시 계정 + 이메일 인덱스 + 선택적 관심정보 삭제
- 이용약관 / 개인정보처리방침 1차 초안 추가
- 만 14세 이상 가입 확인 (1차 빌드에서는 법정대리인 동의 플로우 미지원)

## 멤버십 화면

- FREE: 기본 서비스
- PLUS: 월 5,000원 예정, 기능 범위 표시만 하고 결제는 아직 연결하지 않음
- PRO: `준비중 / 별도 문의`
- ADMIN: 운영용 회원 등급

현재 PLUS 결제 기능을 잠가둔 이유는 계정/동의/등급 데이터가 실제 운영환경에서 먼저 안정적으로 쌓이는지 검증하기 위해서입니다. 관리자에서 테스트 계정을 PLUS 또는 PRO로 변경해 다음 빌드의 권한 테스트 기반으로 사용할 수 있습니다.

## 관심 정당 설계 원칙

공개 NOW Rank와 공개 정치 데이터는 회원의 관심 정당에 따라 변경하지 않습니다.

관심 정당은 향후 `FOR YOU` 등 별도의 개인화 영역에서만 사용합니다. 미선택 또는 동의 철회 시 저장된 선택정보는 제거됩니다. 관리자 회원목록 API에서도 회원의 관심 정당은 노출하지 않습니다.

## Vercel 환경변수

기존 환경변수에 아래 두 값을 추가하는 것을 권장합니다.

```env
USER_SESSION_SECRET=충분히_긴_별도_랜덤값
USER_DATA_ENCRYPTION_KEY=충분히_긴_별도_랜덤값
```

코드는 기존 `ADMIN_SESSION_SECRET`을 비상 fallback으로 사용할 수 있지만 실제 운영에서는 반드시 별도 값을 설정하는 것을 권장합니다.

기존 Upstash Redis 환경변수는 회원 DB에도 그대로 사용합니다.

```env
UPSTASH_REDIS_REST_URL=...
UPSTASH_REDIS_REST_TOKEN=...
```

## 배포 후 확인 순서

1. ZIP 전체를 저장소 루트에 덮어씁니다.
2. Vercel에 `USER_SESSION_SECRET`, `USER_DATA_ENCRYPTION_KEY`를 추가합니다.
3. Production 배포 완료 후 메인에서 회원가입을 테스트합니다.
4. 가입 직후 FREE 등급인지 확인합니다.
5. MY > 내 정치 관심사에서 관심 정당을 선택하고 별도 동의 후 저장합니다.
6. 새로고침 / 재로그인 후 설정이 유지되는지 확인합니다.
7. `/admin.html` > 회원 / 등급 관리에서 해당 계정을 PLUS로 변경합니다.
8. 사용자 계정 재조회 후 PLUS가 표시되는지 확인합니다.
9. 테스트 계정을 탈퇴해 삭제 플로우를 확인합니다.
