# 정참시 v2.2.17 · 회원 데이터 + NOW ISSUE + 자체 설문조사

v2.2.16을 기준으로 회원 데이터 품질, 메인 운영 제어, 사용자 참여 기능을 추가한 버전입니다.

## 1. 회원가입 / MY
- 가입 필수: ID, 비밀번호, 전화번호, 지역, 선호정당
- 이메일: 선택
- 가입 시 최초 닉네임 = ID 자동 설정
- 가입 후 MY에서 닉네임 변경 가능
- MY에서 전화번호, 지역, 선호정당 변경 가능
- 지역: 시·도 → 시·군·구 → 일반구가 존재하는 도시의 구까지 단계 선택
- `특정 정당 없음` 포함
- 선호정당은 별도 동의 후 암호화 저장
- 전화번호/지역도 암호화 프로필 데이터로 저장
- 이메일 미입력 회원도 ID 로그인 가능

## 2. 관리자 NOW ISSUE 관리
관리자 메뉴에 `NOW ISSUE 관리` 추가.
- 메인 노출 ON/OFF
- 상단 라벨
- 메인 제목
- 설명
- 데이터 영역 제목
- 데이터 항목 최대 5개(이름/값)
- 보조 문구
- 출처
- 주의/안내 문구

저장값은 Redis 사이트 설정으로 보관하며 메인 `/api/site-settings`를 통해 반영됩니다.

## 3. 정참시 자체 설문조사
메인 오른쪽 사이드 메뉴에 `정참시 자체 설문조사` 카드 추가.
관리자 메뉴에서 다음을 설정할 수 있습니다.
- 노출 ON/OFF
- 설문 타이틀
- 부제목
- 선택 문항 1~5개
- 현재 응답 수/문항별 집계 확인

투표 정책:
- 설문은 비로그인 사용자도 열람 가능
- 투표는 로그인 회원만 가능
- 회원 1계정당 한 설문에 1회
- 설문 제목/부제목/문항이 바뀌면 새 survey ID를 생성해 기존 응답과 분리
- 노출 ON/OFF만 바꾸면 같은 survey ID와 응답 집계 유지

## 4. 관리자 회원 조회
실회원 상세에서 다음 항목을 함께 확인할 수 있습니다.
- ID / 닉네임 / 이메일
- 전화번호
- 지역
- 선호정당
- 정치적 관심정보 동의 상태
- 회원 등급

## 5. 추가 API
- `GET/POST /api/admin/site-settings`
- `GET/POST /api/site-settings`

Vercel Hobby 단일 gateway 방식은 유지됩니다.

## 6. 데이터/보안 메모
- 비밀번호: scrypt 단방향 해시
- 전화번호/지역: AES-256-GCM 암호화 프로필 저장
- 선호정당: 별도 AES-256-GCM 암호화 영역
- 개인정보처리방침/이용약관은 v2.2.17 가입 흐름에 맞춰 초안을 갱신했으며, 정식 서비스 전 법률 검토가 필요합니다.
