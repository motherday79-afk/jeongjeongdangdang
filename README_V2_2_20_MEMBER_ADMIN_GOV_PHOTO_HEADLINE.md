# 정참시 v2.2.20 · 회원 전체수정 + 정부 주요 인사 사진 + 순위 뉴스 한 줄

v2.2.19의 사이드바 순서 복구, 방문자 일마감, 사진 검수·복구 기능을 유지하면서 운영자 회원관리 권한, 정부 주요 인사 사진 처리, 메인 순위 보조정보를 개선했습니다.

## 1. 어드민 회원 전체정보 수정

실제 회원 상세에서 관리자가 다음 정보를 수정할 수 있습니다.

- 아이디
- 이메일
- 닉네임
- 전화번호
- 지역: 시·도 → 시·군 → 구
- 선호정당
- 회원 등급

비밀번호는 기존 값을 조회하거나 복호화하지 않습니다. 관리자가 새 비밀번호를 입력해 강제 재설정하는 방식이며, 변경 즉시 기존 로그인 세션을 무효화합니다.

가입일, 정치성향 동의 이력 같은 감사용 기록은 읽기 전용으로 유지합니다.

## 2. 정부 주요 인사 사진

기존 화면의 정부 주요 인사 20명을 서버 사진 roster에 별도 등록했습니다.

- NOW Rank 대상 정치인: 기존 542명 유지
- 사진 검색/프록시/캐시/검수 대상: 542명 + 정부 주요 인사 20명 = 562명
- 정부 인사는 이름 + 부처/직위 기반 검색
- 공식 정부·부처 페이지를 우선 후보로 평가
- 메인 정부 카드, 상세, 비교, 사진 검수에서 동일한 서버 사진 시스템 사용

정부 주요 인사는 랭킹 대상에 합산하지 않습니다.

## 3. 순위 이름 아래 해시태그 제거 → 최근 뉴스 한 줄

메인 순위 카드의 이름 아래에 반복 노출되던 WHY NOW 해시태그를 제거하고, 리프레시 시점의 뉴스 스냅샷에서 인물별로 한 줄짜리 뉴스 네이밍을 선택해 보여줍니다.

후보는 최근 수집된 headline / BIG KINDS headline / articleTitles / newsTitles이며 다음 요소를 점수화합니다.

- 해당 인물 이름 포함 여부
- 최신성
- 한 줄로 읽기 좋은 제목 길이
- 발언·결정·논란·반박·승복·합의 등 사건성이 있는 제목
- 포토/영상/단순 브리핑 등 정보성이 낮은 제목 감점

상단 실시간 키워드는 이슈 탐색용으로 유지되고, 정치인 행의 한 줄은 해당 인물의 최근 뉴스 맥락을 보여주는 용도로 분리됩니다.
