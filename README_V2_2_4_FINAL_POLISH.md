# 정정당당 v2.2.4 · FINAL POLISH

오늘 마지막 배포용 마감 패치입니다. v2.2.3 LOCAL COMMUNITY 전체 기능을 유지하면서 메인 단체장 표기와 방문자 표시 관리만 정리했습니다.

## 1. 기초단체장 메인 표기 간소화
- 메인 NOW Rank의 `지역 · 직위` 칸에서 기초단체장은 지역명을 다시 붙이지 않습니다.
- 예: `경기도 · 고양시장` 또는 `경기도 고양시 · 고양시장` → `고양시장`
- 예: `경기도 · 용인시장` → `용인시장`
- 광역단체장도 기존과 동일하게 `경기도지사`, `울산광역시장`처럼 직위만 표시합니다.
- 상세 프로필의 관할 지역 정보 자체는 삭제하지 않았습니다. 메인 목록만 간결하게 정리했습니다.

## 2. 방문자 표시 관리
- 실제 방문자 집계는 기존 Redis HyperLogLog/ZSET 구조 그대로 유지합니다.
- `현재 접속`은 조작하지 않고 최근 5분 실제 접속만 표시합니다.
- `오늘 방문`, `누적 방문`은 관리자 화면에서 표시 목표값을 지정할 수 있습니다.
- 저장 시 실제값을 덮어쓰지 않고 `표시값 - 실제값`의 차이만 보정값으로 Redis에 저장합니다.
- 이후 실제 방문자가 증가하면 화면 표시값도 함께 증가합니다.
- 실제 집계보다 낮은 표시값은 설정할 수 없습니다.
- 관리자 화면에는 실제값 / 표시값 / 적용 보정값을 모두 따로 보여 운영자가 언제든 확인할 수 있습니다.
- `실제 집계값으로 초기화` 버튼으로 보정값을 즉시 0으로 되돌릴 수 있습니다.

## 관리자 사용법
1. `/admin.html` 로그인
2. `방문자 표시 관리`에서 오늘 방문/누적 방문의 원하는 표시값 입력
3. `방문자 표시값 저장` 클릭
4. 메인 새로고침 후 확인

별도 환경변수는 필요하지 않습니다. 기존 Redis를 그대로 사용합니다.
